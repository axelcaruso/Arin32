# Security Policy

## Supported Versions

Security updates and vulnerability patches are actively provided for the following releases of Arin32:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0.0 | No                 |

## Reporting a Vulnerability

We take the security and integrity of Arin32 and the ArinOS ecosystem seriously. If you identify a security vulnerability, please report it responsibly:

1. **Do not disclose publicly**: Please refrain from opening a public GitHub issue or publishing details before a fix is coordinated.
2. **Contact maintainers**: Send an email to security@arinos.org with details regarding the potential vulnerability.
3. **Include details**: Provide a clear description of the vulnerability, step-by-step reproduction steps, proof-of-concept code (if available), and the affected platforms or compilers.

We will acknowledge receipt of your vulnerability report within 48 hours and provide a timeline for triage and resolution. Once patched, a public disclosure and security advisory will be published alongside the fixed release.
